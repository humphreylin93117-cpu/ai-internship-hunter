## Project 1 — Campus Event Data Explorer (fictional)

- Type: Personal learning project
- Status: Local prototype
- Role: Sole developer
- Stack: Python, pandas, FastAPI, SQLite, pytest

### Problem

### Implemented work

- Designed a normalized event record and SQLite persistence layer.
- Added CSV import, validation, duplicate detection, and filtering.
- Exposed REST endpoints with FastAPI and Pydantic schemas.
- Added unit tests for parsing, persistence, and API behavior.

### Evidence boundaries

- This is a local learning prototype, not a production deployment.
- No commercial users, revenue, or business impact are claimed.
